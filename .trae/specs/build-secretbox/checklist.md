# Checklist

- [x] 首访问 / 或 /api/status 正确反映未设置主密码状态
- [x] 设置主密码后能进入主界面;重启后需解锁,错误密码被拒绝
- [x] 加密层往返一致;错误密钥/密码无法解密
- [x] SQLite 落盘数据为密文,无明文隐私
- [x] 新增条目后列表出现且可读取解密值
- [x] 编辑条目后 updated_at 更新,并生成新版本快照(含修改时间)
- [x] 可查看某条目全部版本历史
- [x] 还原到旧版本后当前内容被替换,且该还原生成一条新版本记录
- [x] 删除条目后其历史版本一并清除
- [x] 锁定后界面回到解锁页,且无法读取/修改任何条目
- [x] 搜索可按标题/分类过滤
- [x] 前端界面布局合理(列表/编辑区/版本历史),交互无报错(控制台无异常、网络请求 2xx)
- [x] go build 产出单个 .exe,双击即可运行,不依赖外部文件/Python
