# 04 — 历史版本：查看 / 恢复 / 删除

**What to build:**
条目每次修改自动留存历史版本；用户可查看、恢复、删除历史版本；删除历史版本时要求输入主密码确认。

**Blocked by:** 03 — 条目增删改查 + 删除主密码确认

**Status:** done

> 实施说明：
> - "查看"按 CONTEXT.md 领域词汇补齐：点击版本号区域在保密内容区显示该版本明文
>   （Go 版只有还原/删除，此交互不改变行样式，基准截图不受影响）。
> - 恢复/删除流程与 Go 版一致：还原弹确认（生成新修改记录），删除需主密码
>   （受 delete_version_requires_password 设置控制）。
> - 集成测试教训：写路径测试复制 .db 前必须 checkpoint_wal()，否则副本缺 WAL 中的最新写入。

- [x] Rust 集成测试：删除历史版本必须验证主密码
