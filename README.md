# SecretBox

本地加密密码管理器（Rust + Tauri 桌面应用）。数据使用 **随机数据密钥（DEK）+ AES-256-GCM** 加密后存入 SQLite；DEK 由主密码和恢复密钥两把钥匙分别包装保管，两个明文秘密都不落盘；双击即用，无需浏览器、无网络依赖（存储格式见 ADR-0003）。

## 功能介绍

- **主密码保护** — 首次设置主密码后，所有条目加密存储；每次启动需解锁，支持锁定与自动锁定（默认 120 秒）
- **恢复密钥** — 首次设置时强制生成并要求抄写保存；忘记主密码时凭它重设主密码找回全部数据（锁屏"忘记主密码"入口）
- **条目管理** — 新增/编辑/删除密码、账号等条目，支持分类与备注
- **版本历史** — 每次修改自动保存历史版本，可随时查看、恢复或删除旧版本
- **数据迁移** — 加密导出/导入完整数据快照（含历史版本），快照同时携带主密码与恢复密钥两份包装——主密码或恢复密钥都能导入恢复；导出后可一键清除本地痕迹
- **安全设置** — 修改主密码（秒级完成，只重新包装密钥）、查看/重新生成恢复密钥（旧码立即作废）；可要求删除条目/版本时输入主密码确认

## 安装

从发布产物获取单个 exe（`SecretBox.exe`），双击即可运行。桌面渲染依赖 WebView2，Windows 11 已内置，Windows 10 如缺失系统会自动提示安装。

自行构建：

```bash
npm install
npm run tauri build
```

产物位置：

| 产物 | 路径 |
| --- | --- |
| 便携单文件 exe | `target\release\secretbox.exe` |
| NSIS 安装包 | `target\release\bundle\nsis\SecretBox_0.1.0_x64-setup.exe` |
| MSI 安装包 | `target\release\bundle\msi\SecretBox_0.1.0_x64_en-US.msi` |

## 便携模式

默认情况下，数据库存放在用户数据目录（Windows：`%LOCALAPPDATA%\SecretBox\secretbox.db`）。

用 `--db` 参数指定任意位置即可进入便携模式，数据文件随指定目录走（例如放在 U 盘里随身携带）：

```bash
secretbox.exe --db D:\sb-portable\secretbox.db
# 等价写法
secretbox.exe --db=D:\sb-portable\secretbox.db
```

## 旧版本数据库升级

v2 之前的数据库（条目直接由主密码加密）在启动时会自动被升级向导拦截：输入主密码 → 数据与历史版本原样迁入新格式 → 强制生成恢复密钥，之后旧文件以 `.v1.bak` 归档保留。升级不可跳过；任何中断旧库原样未动，可重新走向导。

## 数据安全

- 主密码与恢复密钥都不落盘（恢复密钥仅以密文形式可回显）；**两者丢失任意一个，另一个仍能恢复数据；两个都丢失则数据不可恢复**，恢复密钥请抄写在纸上妥善保管
- 条目由随机数据密钥（DEK）加密；主密码与恢复密钥各自派生密钥包装 DEK，错误密码/错误恢复码都会被 GCM 认证标签拒绝
- 数据文件、导出的快照均为 AES-256-GCM 加密，离开两把钥匙不可读
- 删除条目/版本时可要求输入主密码二次确认（设置中开启）
